# Quick Notes

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: FastAPI (Python) + Pydantic
- Database: PostgreSQL + TortoiseORM + Aerich
- Package manager: Poetry
- Auth (later): Firebase Auth
- Email: SendGrid
- Calendar: Google Calendar API
- Hosting: Local → Docker → Fly.io or university system
- Dev Tools: pytest, Docker, dotenv, pre-commit, ruff

## Why PostgreSQL?
More modern and better at scaling. Good for future-proofing.

## Why Poetry?
Steeper learning curve but more reliable and better for publishing packages. Future-proofing.
