🔹 2. Setup PostgreSQL and Connect to It
Start with a local PostgreSQL server (e.g. Docker or installed)
Connect FastAPI to the database using an ORM like SQLAlchemy or Tortoise
Prompt: Would you like strict typing support from your ORM? Why might that matter long-term?

🔹 3. Create the First Table: Student
Write a basic model class for students
Create a simple CLI or script that lets you:

🔹 4. Write Your First Tests
Setup pytest
Write a test for:
Adding a student
Removing a student
Handling errors (like duplicate names or bad input)
Prompt: What’s the benefit of testing edge cases right now, before any UI or frontend?

🔹 5. Add Logging & Error Handling
Use Python's logging module
Create a custom exception handler
Print helpful logs and errors — aim for clarity over cleverness
